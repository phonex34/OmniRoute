- **fix(sse,combo):** a codex turn that ends normally with no text (`content:null`, `finish_reason:"stop"`, `reasoning_tokens > 0` — e.g. a watchdog agent choosing silence) is now a valid 200 on every path instead of a synthetic `502 Provider returned empty content`. Follow-up to [#14160](https://github.com/diegosouzapw/OmniRoute/issues/14160) / [#14243](https://github.com/diegosouzapw/OmniRoute/pull/14243), which only covered antigravity on the non-streaming leg: the stream content watcher (#8649) and both combo quality gates (#10404 streaming, non-streaming empty check) now share one `isTrustedEmptyStop()` rule, so a codex-only combo no longer fails every target on the same silent answer. Codex is trusted only when reasoning tokens prove the model ran; empty shells, untrusted providers, and every other terminal reason keep failing over.
